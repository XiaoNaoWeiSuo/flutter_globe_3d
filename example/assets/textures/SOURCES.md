# Example Textures and Sources

All added textures are bundled locally with the example and work offline. They are 2048 × 1024 and use the component's equirectangular (lat-long) mapping. No baked lighting is included.

## Regenerate or replace assets

Install `numpy` and `Pillow` at the repository root, then run:

```sh
python3 example/tool/generate_textures.py
```

The script regenerates six original textures. Material assets can be downloaded as 1K JPG archives from the ambientCG pages above. Use the `_Color.jpg` file, preserve its original 1024² resolution, and tile it twice horizontally.

An earlier soccer example used [Mustitz's CC0 texture](https://opengameart.org/content/soccer-ball-animation-sprites-and-3d-texture). It has been replaced with an original, high-resolution geometric texture; the old low-resolution file is no longer bundled. Do not use rendered-sphere preview images from asset websites as sphere textures.

`SphereView` currently samples only color maps; it does not support PBR normal, roughness, or metallic channels. Equirectangular mapping stretches tiled materials near the poles, so these three material examples demonstrate color textures only.
